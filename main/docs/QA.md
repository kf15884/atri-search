## 覆盖

- 旧0.1.0历史/state数据格式兼容、最近20词、权限、额度、去重、暂停保持；不清HDS库。
- 草稿丢弃零外部动作、正式提交/源剧本匹配后入队、取消/重置/来源删除、前台忙碌让位、聊天不等后台。
- 浏览器优先、浏览器失败/空结果切单次API；策略阻止或取消不兜底；两线路失败回流failed“未获取信息”；迟到结果不覆盖。
- 两端真实HTTP创建/轮询/提交回执；重复创建幂等、服务重启未知不重放、租约和取消。
- 最近查询只记录实际提交；同一回执不重复记录、浏览器加API两次尝试记录两条但只占一次逻辑任务额度。
- 自定义API只发送公开query/count/need_content:false，不附原问题或定位IP；HTTPS、公网DNS检查及固定地址，拒绝跳转与超大响应。
- 第二台鉴权、私有监听、查询过滤、拒绝非只读操作；内部实际代理阻止本机/私网请求与CONNECT，DNS混合私网拒绝。
- **真实Chromium + Playwright**在本地模拟搜索页完成打开、fill、Enter、实际DOM结果提取。没有启动浏览器访问公网搜索引擎。
- **真实Koishi4.18.11 + HDS rc57 + SQLite4.7.0**两种加载顺序：提交→资料回流→源删除→卸载。
- **当前故事人设追加的数据保全**：在真实HDS/SQLite中保存已有演化、记忆、参与者、剧本；preview不改，apply只追加原profile；逐项比较故事ID、state/overlay、所有既有记忆/参与者/剧本保持。先备份、并发人设变化拒绝覆盖、权限拒绝不写、相同段落去重。
- 功能接入为明确手动管理员注记、去重；第二台失联不编造已接入事实；不替用户发言、不注入虚构情绪。
- SQLite data-guard真实一致性备份/完整性检查、只读内容比对；发现新数据只报差异，不自动修复/恢复/删除。
