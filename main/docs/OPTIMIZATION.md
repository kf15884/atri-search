# Atri子插件优化原则（不改HDS核心）

本地路由/缓存 → HDS原叙事 → 正式剧情提交 → 后台副作用 → 实际证据回流 → HDS决定感想/记忆/分享。

- 不在叙事草稿返回时执行外部动作；丢弃草稿不能生成照片或触发搜索。
- 不为每条聊天加一个意图判断模型；不等待搜索或后台向量计算。
- 复用宿主已有上下文、查询向量、故事代际和投递许可。
- 背景工作开始前让位主叙事；正在处理的低优先级网络不阻塞新聊天。
- 剧情行动绑定正式剧本；“已发送”才需要实际投递证据，二者不是一回事。
- 暂停、重置、源删除、身份变化、卸载和重启都要处理；保留未知不重放策略。
- 照片：优先修正提交前生成风险；保留看图/分级，非必要embedding不阻塞当场发。
- B站：自动候选后台预取；生成感想前让位；保留已有回执和30–90秒节奏。
- 日记：依赖顺序不变，增加分阶段检查点；周期检查并非每次都调用模型。
- 搜索：正式提交后单次检索；历史只留最近20条实际提交查询；摘要不是全文；插件不直接推送。

本包只实现搜索子项目，上述其他插件的优化仍是指南，不冒称已经改完。
